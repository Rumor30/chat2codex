# 安全边界

## 本地访问与凭据

网关仅监听 `127.0.0.1`。除静态页面、无账号信息的健康检查和一次性本地邀请兑换外，管理/模型接口都需要随机 bearer key。Host/Origin 校验、CSP、禁止 worker 重定向减少跨站调用风险。这不是公网多租户服务，不应简单端口转发出去。

控制台密钥只存于当前页面内存；启动邀请一次性且短期有效，使用后移除 URL fragment。Tunnel runtime key 通过本地请求和子进程 stdin 传递，表单清空，不写入 argv、配置操作回执或导出诊断。真正的运行密钥由上游保存到对应账号的私有目录。

浏览器 Cookie/ChatGPT 登录态留在各自 Electron profile。身份检查仅输出带启动期随机盐的哈希；不要导出整个 profile 或原始认证网络流量。Unix 目录/密钥使用 0700/0600；Windows 依赖用户目录 ACL。不能防御同一系统用户下已经能读文件的恶意程序。

## 设置与权限

Electron 设置扩展只允许固定的账户范围动作，不接受任意代码或任意地址；网页禁用 Node 集成并启用隔离/沙箱。设置助手要求明确授权，验证精确 Tunnel identity；不确定控件、同名服务或创建中断时停下复核。

助手不会绕过 2FA、重新认证、工作区管理员策略或额外写入授权。登录 session 不等于服务端 entitlement。没有实现猜测性的私有 Connector 创建 endpoint。

原生工具仍由外层 Codex 的实际沙箱与审批执行。网页模型提出 tool call 不等于绕开用户权限。生产路径没有模拟 shell/patch 成功执行器；nonce 探针只允许它自己声明的无副作用回显工具。

## 一致性与恢复

同一线程/工具轮次固定账号；不以账号轮换规避限额，也不在失败后跨号重放可能有副作用的工具。取消不撤销已经发生的文件修改。

线程释放保留追加式哈希重放日志；未完成请求、撕裂的状态文件或未知工具回执失败关闭。磁盘写入问题会停止新增模型工作而保留控制台。不要为了消除错误删除所有状态并重试旧工具请求。

死锁回收只用于确认 PID 不存在且锁文件未变化的情形；活进程或权限不明不能强抢。PID 重用宁可产生需要人工处理的保守阻塞，也不抢占另一个工作进程。

## 供应链与桌面运行

浏览器桥、依赖和公开 Codex 模型目录固定版本；profile 常量 overlay 验证原始 Git blob，拒绝覆盖额外源码修改。模型模板和许可证也校验其固定 Git blob。依赖安装仍会运行对应安装脚本，升级前需审阅。

Linux 正常的 Electron sandbox helper 安装可能要求管理员设置文件所有者与权限。程序不会自动提权、关闭沙箱或绕开管理员的系统策略。构建/CI 脚本中的系统配置仅用于一次性 runner。

本项目是非官方集成，实际使用受服务条款、账户权限和网页变化影响。更多真实账号安全验收项见 RELEASE_CHECKLIST.md。
